# 开始使用 Milo

Milo 是你的水豚日程抄写员。它待在屏幕顶部菜单栏，把截图或文字里的安排整理成可以修改的纸条。

## 第一次打开

1. 将 Milo 移入 Applications，启动后点击菜单栏中的水豚。
2. 打开设置，添加你自己的识别服务与模型，检查连接后保存。
3. 按系统提示允许所需权限：截图需要屏幕录制权限，保存安排需要日历或提醒事项权限。

如果从 AIScheduleAssistant 升级，请先退出旧版，避免同时出现两个菜单栏入口。原有本机设置会继续沿用。

## 截图或输入

选择「截图获取」后，直接圈选需要整理的区域；不想继续时按 Esc 取消。

选择「文本输入」后，在原来的小窗里粘贴或输入消息，选择模型，再提交整理。关闭小窗后，未提交的文字会清空；下次打开回到初始菜单。

整理期间仍可继续提交其他内容，各份结果会分别保留并打开。

## 核对纸条

直接点进标题或正文即可编辑，回车可以换行。日期、时间和保存位置可展开调整；地点和链接有需要时也能修改。

勾选本次需要的条目，再选择保存到日历、待办或两处。「全选」和「全不选」对全部条目生效，包含其他页的纸条。内容多时，可用翻页按钮或在纸条区域左右滑动切换。

确认后点击「添加」，窗口会关闭，Milo 继续保存安排。若有未完成的保存，会给出提示，成功的部分不会因重试而重复添加。

## 找回以前的结果

从菜单栏进入「历史记录」，可以查看过去的结果、耗时及服务提供的用量信息。打开某条记录即可继续核对，无需重新识别相同内容。

可在设置中调整保留时间和数量，也可以主动清理。删除 Milo 中的历史不会删除已经写入系统日历和提醒事项的安排。

## 关于隐私

识别时，你主动提交的内容会发送给你选择的识别服务。历史保存在本机，Milo 不提供云端历史同步。截图原图默认不保留，开启留存后也会随相关历史一起清理。

反馈问题时，请使用虚构示例，并遮住个人信息与连接凭据。
