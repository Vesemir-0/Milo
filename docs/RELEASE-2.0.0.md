# Milo 2.0.0

你的水豚日程抄写员，带着全新的名字和纸条回来了。

截图或输入一段消息，Milo 会把里面的安排整理好。你可以先修改标题、正文、时间与地点，再选择添加到系统日历、待办，或同时保存到两处。

## 这次更新

- **全新的抄写员界面。** 暖色纸条、同一只水豚的新图标，更清楚的内容层次与更轻盈的窗口。
- **先编辑，再添加。** 标题与正文支持换行，日期、地点及保存目标可以逐项调整。
- **多项安排更好核对。** 分组翻阅、跨页全选与全不选，长内容也能从容修改。
- **菜单栏直接输入。** 文本输入、模型选择和提交都在原来的小窗里完成。
- **连续提交，分别整理。** 上一份尚未完成，也可以继续截图或输入；每份结果独立保留。
- **多组服务与模型。** 保存常用选项，快速切换，并可提前检查连接。
- **本机历史记录。** 找回识别结果、查看耗时和用量，按需要保留或清理。
- **减少打断。** 截图按 Esc 取消，更清楚的错误解释、更合理的等待，以及更容易点击的按钮和条目。

## 下载与安装

需要 **macOS 14.6 或更新版本**，支持 **Apple Silicon 与 Intel**。

- `Milo-v2.0.0-universal.dmg`：打开后，将 Milo 拖入 Applications。
- `Milo-v2.0.0-universal.zip`：解压后，将 Milo 移入 Applications。
- `Milo-v2.0.0-SHA256SUMS.txt`：下载文件校验信息。

如果正在运行 AIScheduleAssistant 或旧版 Milo，请先退出，再安装。原有本机设置会继续沿用。

启动后点击菜单栏水豚，设置自己的识别服务并选择模型，即可开始使用。
